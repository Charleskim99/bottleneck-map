왼쪽 표에서 주제를 누르면 근거 문장과 출처가 여기에 나옵니다.

EndNote용 RIS 내려받기

초록 문장 한 줄을 넣으면 병목인지 해결 주장인지 판정합니다

1차 판정은 브라우저 안에서 신호 단어로 합니다(키 필요 없음). AI 판정은 서버 함수가 LLM을 호출하며, 배포 환경에 API 키가 있을 때만 동작합니다.

판정 기준

bottleneck: 아직 부족·제한·미해결·불안정·비용 같은 문제를 말하는 문장. resolution-claim: 그런 문제가 이제 해결·제거·불필요·일상화됐다고 말하는 문장. neither: 방법 설명, 측정값, 목표 문장. 인용은 문장 안의 연속된 구절만 허용합니다.

최근 판정 기록

이 브라우저에 저장됩니다(새로고침 후에도 유지). 다른 기기와는 공유되지 않습니다.

    무엇을 보여 주는가

    이 화면은 Claude Code 스킬 intro-funnel이 만든 세 가지 결과를 읽기 위한 초안입니다. 병목 지도(초록에서 아직 한계로 적히는 문제와 해결했다고 주장하는 문제를 갈라 센 표), 분야 동향 요약(축별 최신 논문과 승인된 근거), 인트로 참고문헌(하향식 체인 순서의 23편)입니다. 모든 근거 문장은 공개 초록에서 그대로 옮긴 것이고 DOI로 레지스트리(Crossref)와 대조한 것입니다.

    화면 · 처리 · 저장 · 배포

    • 화면: 정적 HTML·CSS·JS. 빌드 도구 없이 바로 열립니다. 주소의 해시로 특정 주제나 문장을 바로 열 수 있습니다(#tab=map&theme=BN02, #tab=label&s=문장).
    • 처리: 신호 단어 판정은 브라우저에서, AI 판정은 Vercel 서버 함수(api/label.py)에서 합니다. API 키는 서버 환경변수에만 둡니다.
    • 저장: 내 판단·메모·판정 기록은 지금은 브라우저 localStorage에 둡니다. 계정별 저장(Supabase)은 다음 단계입니다.
    • 배포: Vercel. 저장소를 가져오기만 하면 됩니다.

    아직 안 되는 것

    • 로그인이 없어서 판단이 기기마다 따로 남습니다.
    • AI 판정은 키가 설정된 배포 환경에서만 동작합니다.
    • 데이터는 실행 결과를 내보낸 정적 파일이라 새 실행을 반영하려면 다시 내보내야 합니다.
